**EPGP** - система распределения добычи в рейде по очкам усилий (EP) и очкам экипировки (GP). EP начисляются за участие в рейде, GP - за полученные предметы, а приоритет на добычу определяется отношением EP к GP. Значения хранятся в офицерских заметках гильдии.

/epgp - открывает и закрывает окно EPGP.
/epgp help - список команд.

**EPGP LootMaster** - распределение добычи между игроками для мастера лута и рейда.

/lm config - настройки.
/lm toggle - показать или скрыть окно.
